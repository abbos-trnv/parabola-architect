# От чертежа к функции

Практический мини-курс «Бюро форм» для 9 класса. Ученик проектирует переправу, применяя координаты, линейные и квадратичные функции.

[Карта курса](https://parabola-atelier-9.pearly-mars-8154.chatgpt.site/) · [Архитектор парабол](https://parabola-atelier-9.pearly-mars-8154.chatgpt.site/parabola.html) · [Запись экрана](media/demo.webm)

![Карта курса с тремя практическими уроками](media/preview.png)

## Уроки

1. **Разметка опор.** Поставить первую точку по описанию и прочитать координаты второй с чертежа.
2. **Линия подъёма.** Подобрать наклон пандуса и высоту его начальной точки по двум площадкам.
3. **Архитектор парабол.** Исследовать три коэффициента, построить арку и рассчитать, пройдёт ли под ней катер.

Каждый урок доступен с карты. Выполненные задания сохраняются в локальном хранилище браузера.

## Запуск

Откройте `index.html` или запустите любой статический веб-сервер в корне проекта. Для прохождения с сохранением прогресса между страницами используйте веб-сервер. Сайт написан на HTML, CSS, JavaScript и SVG и не требует сборки.
