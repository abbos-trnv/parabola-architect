# Архитектор парабол

Интерактивный тренажёр по квадратичной функции для 9 класса. Ученик меняет коэффициенты в уравнении **y = ax² + bx + c** и сразу видит, как перестраивается график.

[Открыть тренажёр](https://parabola-atelier-9.pearly-mars-8154.chatgpt.site/) · [Посмотреть демонстрацию](media/demo.webm)

![Тренажёр с ползунком коэффициента a и графиком](media/preview.png)

## Как устроен урок

1. Изменить **a**, чтобы развернуть ветви и подобрать ширину параболы.
2. Изменить **b** и проследить за движением вершины и оси симметрии.
3. Изменить **c**, чтобы переместить график по вертикали.
4. В мастерской управлять всеми коэффициентами, построить арку по размерам и проверить, пройдёт ли под ней катер.

## Локальный запуск

Скачайте репозиторий и откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.

Интерфейс написан на HTML и CSS. JavaScript отвечает за задания и обратную связь, SVG — за построение графиков и иллюстрацию арки.
